Notes/Issues: 
3A.  ** iForest introduces data leakage: It decides what a normal data point is. We can't use the test set for that.
	We can leave outliers in the test set.
4. Because scaling and iForest happened before the split, this allows data leakage doesn't it?
	Scaling involves using the variance and mean of the whole dataset, including the test set.
5. We are running 2 different versions of SMOTE on 2 different feature spaces (scaled vs unscaled).
	This will mean we have completely different SMOTE data -> not an equal comparison
